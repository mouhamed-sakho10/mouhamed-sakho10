## 🏥 Featured project: SenDoc

**A medical appointment booking platform for Senegal** ([sendoc.sn](https://sendoc.sn)).

Patients find a doctor and book an appointment online, without phoning. Doctors and their secretaries manage the clinic's agenda in one place, and patients get automatic reminders on WhatsApp to reduce no-shows. Built mobile-first for the Senegalese context.

I designed and built it end to end, and I run it in production on my own server.
